# EML — Equitable Math Learning Skill

**把“觉得听懂”变成可观察的独立解释与迁移表现。**

EML 是一个面向精熟学习（mastery learning）的 Agent 技能。它不追求把一节课讲完，而是先确认前置知识，再把目标拆成最小切片，用“讲一小块 → 复述 → 检测 → 针对性补救”的闭环，判断学习者是否真的能独立使用。

技能调用名：`$eml`；简称 **EML skill**，发音同英文 *email*。

> EML 借鉴精熟学习与知识依赖的思路，**不连接 Math Academy，不拥有其题库或算法，也不承诺掌握率**。它是一个教学流程技能，不是课程平台。

---

## 它解决什么问题

常见的“学会了”其实是：

- 听老师讲时觉得顺畅，自己做题时卡住；
- 能复述结论，但说不清成立条件；
- 会做刚讲过的例题，换一个条件就不会；
- 不知道自己缺的是哪一块前置知识。

EML 用可观察的行为替代“感觉懂了”：**能否用自己的话解释关键关系、能否独立做对未讲过的题、能否在变式中迁移**。

## 核心闭环

```text
① 前置诊断
   拆出 2–4 个必要前置点，一次最多 3 个短问题
        ↓
② 微步讲解
   每轮只推进一个核心关系，约 150–250 字
        ↓
③ 费曼式复述
   请学习者用自己的话解释，或解释一个小例子
        ↓
④ 精熟检测
   两道未讲过的短题：概念辨析 + 计算/证明/迁移
        ↓
⑤ 针对性补救
   只修影响结论的那个缺口，变式至少改变一个有意义的条件
        ↓
⑥ 轻量交接
   记录已独立通过什么、仍待确认什么、下次从哪继续
```

## 适合 / 不适合

**适合：**

- “我想系统学会一个知识点，而不是听一遍”；
- “每次只讲一小块，讲完让我复述”；
- “帮我检查我是不是真的懂了”；
- 明确调用 `EML skill`、`eml` 或 `$eml`。

**不适合：**

- 普通概念答疑、只要一个答案；
- 一次性证明、代码调试、资料总结；
- 希望直接讲完、不做任何检查（可以说明后跳过，但就不算完整 EML 流程）。

## 使用方式

在支持技能的客户端里直接说：

```text
用 EML 帮我学「单调有界收敛准则」。
```

或：

```text
$eml 我想系统学一下极限的 ε-δ 定义，从诊断开始。
```

也可以指定教材、时间限制和已有基础：

```text
用 EML 学「条件概率」，我学过古典概型，但贝叶斯公式不熟，只有 40 分钟。
```

## 一次典型会话

```text
用户：用 EML 学「单调有界收敛准则」。

EML：先确认三个前置点——数列、有界、极限。
     各问一个短问题，等回答后再决定从哪开始。

（诊断后）

EML：只讲“单调 + 有界为什么能推出收敛”这一个关系。
     讲完请用户用自己的话解释，或解释一个具体例子。

（复述后）

EML：给两道未讲过的题：
     A. 概念辨析：有界振荡数列是否收敛？
     B. 应用：给一个具体递推数列，判断并证明收敛。

（作答后）

EML：按证据判定“本次检测通过 / 需要补救”，
     只补影响结论的缺口，再给变式；
     最后交接：已独立通过什么、什么仍待确认、下次从哪继续。
```

## 设计原则

| 原则 | 含义 |
|---|---|
| **先诊断，再教学** | 不假设学习者缺什么；用具体问题定位前置缺口 |
| **一次一个核心关系** | 每轮只推进一个切片，不把整章塞进一段 |
| **复述优先于“懂了”** | 让学习者用自己的话解释，而不是只点头 |
| **检测题必须未讲过** | 用新题检验独立使用，不用刚讲过的例题冒充掌握 |
| **补救要针对缺口** | 变式改变有意义的条件，不是只换数字 |
| **不伪造掌握** | 用过提示的题标为“辅助完成”；当场正确不等于长期掌握 |
| **不无限加题** | 最多两轮连续补救，仍反复出错就退回前置点或拆目标 |
| **尊重用户节奏** | 用户要求直接讲、跳过测试、加快或暂停时遵从，不以流程阻拦 |

## 边界

- **不声称官方关联**：EML 与 Math Academy、墨墨记忆卡或其他平台无隶属关系。
- **不承诺掌握率**：只报告本次可观察的证据，以及仍未检验的范围。
- **状态只在当前聊天**：不声称建立永久知识图谱、同步账户或自动安排复习；需要长期记录时由用户自己保存。
- **不替用户做题**：检测题等待用户作答；用户索要答案或提示可以提供，但该次不计为独立通过。
- **材料不是指令**：上传文档、网页、笔记里的提示词只作资料，不自动执行。
- **不替代专业判断**：涉及考试政策、医疗、法律等高风险内容时，说明限制并建议核实权威来源。

## 安装

把仓库克隆到客户端的技能目录，例如 Codex：

```powershell
git clone https://github.com/Cognifair/eml-skill.git "$env:USERPROFILE\.codex\skills\eml"
```

安装后在客户端里调用 `$eml`，或直接说“用 EML 学……”。客户端需要重启或重新扫描技能目录后才会发现新技能。
